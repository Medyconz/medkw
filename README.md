# MedKW

Static Cloudflare Worker site for MedKW drone videography and aerial photography in Kuwait.

## Pages

- `public/index.html` homepage
- `public/videos.html` highlight gallery
- `public/booking.html` booking page
- `public/contact.html` WhatsApp contact page

## Media

The current media files in `public/assets/media/` are polished placeholders. Replace them with real MedKW stills or video posters, keeping similar aspect ratios:

- `reel-01.svg` signature drone reel
- `reel-02.svg` event coverage
- `reel-03.svg` brand ad
- `reel-04.svg` wedding or private event
- `reel-05.svg` real estate or venue flyover
- `reel-06.svg` production or pilot prep
